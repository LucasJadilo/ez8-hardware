# EZ8 Hardware

This repository contains all hardware-related files for the EZ8 CPU:

- Documentation that describes the Instruction Set Architecture (ISA).
- All circuit schematics, including test circuits.
- All circuit simulation files.
- Digital timing diagrams generated by test simulations.

The EZ8 is a fully simulated 8-bit RISC CPU designed from scratch as a hobby project.
Check the complete CPU documentation on [Hackster](https://www.hackster.io/LucasJadilo/ez8-8-bit-cpu-from-scratch-6d22d8).

The entire CPU circuit was designed, simulated, and tested using the software
[Proteus Design Suite](https://www.labcenter.com/) 8.6 SP2 from Labcenter Electronics.
First, each module was designed and tested individually, then the entire system
was connected and tested as a whole.

To use the EZ8 CPU module in other projects, the following files must be placed
in the same directory as the project file (`.pdsprj`):

| File                                                      | Description                         |
|-----------------------------------------------------------|-------------------------------------|
| [EZ8.MOD](simulations/system/EZ8.MOD)                     | Top-level CPU module                |
| [Acc.MOD](simulations/system//Acc.MOD)                    | Accumulator module                  |
| [BReg.MOD](simulations/system/BReg.MOD)                   | B Register module                   |
| [ALU.MOD](simulations/system/ALU.MOD)                     | Arithmetic Logic Unit module        |
| [IReg.MOD](simulations/system/IReg.MOD)                   | Instruction Register module         |
| [PC.MOD](simulations/system/PC.MOD)                       | Program Counter module              |
| [DAR.MOD](simulations/system/DAR.MOD)                     | Data Address Register module        |
| [SP.MOD](simulations/system/SP.MOD)                       | Stack Pointer module                |
| [BIU.MOD](simulations/system/BIU.MOD)                     | Bus Interface Unit module           |
| [CU.MOD](simulations/system/CU.MOD)                       | Control Unit module                 |
| [CUBuf.MOD](simulations/system/CUBuf.MOD)                 | CU's output buffer                  |
| [ez8_cu_eprom0.bin](simulations/system/ez8_cu_eprom0.bin) | CU's EPROM data (output bits 0-7)   |
| [ez8_cu_eprom1.bin](simulations/system/ez8_cu_eprom1.bin) | CU's EPROM data (output bits 8-15)  |
| [ez8_cu_eprom2.bin](simulations/system/ez8_cu_eprom2.bin) | CU's EPROM data (output bits 16-23) |
| [ez8_cu_eprom3.bin](simulations/system/ez8_cu_eprom3.bin) | CU's EPROM data (output bits 24-29) |

The CU's EPROM files were generated by [software](https://github.com/LucasJadilo/ez8-microcode).

If the RAM module is also used to store the program (most likely will), the following
files must also be placed in the same directory as the project file:

| File                                      | Description                                  |
|-------------------------------------------|----------------------------------------------|
| [RAM.MOD](simulations/system/RAM.MOD)     | RAM module                                   |
| [Bus3S.MOD](simulations/system/Bus3S.MOD) | Tri-state bus buffers used in the RAM module |
